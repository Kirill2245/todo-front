# Listodo — редактор заметок

SPA-приложение на Vue 3 по практическому заданию №2: заметки со списками дел.

## Стек

- Vue 3
- Vue Router
- Bootstrap 5
- Bootstrap Icons
- SweetAlert2

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
npm run preview
```

## Страницы

- `/` — главная: список заметок и редактор выбранной заметки;
- `/rate` — оценка приложения;
- `/about` — информация об авторе.

## Функционал

- создание, переименование и удаление заметок (удаление с подтверждением);
- добавление, редактирование и удаление задач;
- отметка задач как выполненных;
- адаптивная вёрстка для десктопа и телефона.
